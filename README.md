# Lazarus

Med math drills, drug profiles with a dose calculator, scenarios and a registry simulator for medics. Built for PILLAR training.

The app lives in `docs/` and is served by GitHub Pages. Open the Pages URL on a phone and use Add to Home Screen; it runs offline after the first load.

Doses are standard published ranges and the WVFD profile set. Verify every number against local protocol before use on a patient.
